# Agent skills

`mica/SKILL.md` teaches a coding agent when to hand a decision to Mica, how to write the request, and how to call the
server efficiently.

- Claude Code: copy the folder to `~/.claude/skills/mica/` (all projects) or `.claude/skills/mica/` (one project).
- Other agents: add `mica/SKILL.md` to the agent's instructions or project rules.
